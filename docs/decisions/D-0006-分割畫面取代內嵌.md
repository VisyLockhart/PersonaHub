# D-0006 以 Chrome 分割畫面取代 iframe 內嵌，入口頁改為側欄版面

| | |
|---|---|
| 狀態 | 有效 |
| 日期 | 2026-11-21 |
| 決定者 | 使用者（提出左側選單＋右側服務畫面），細節由 Claude 擬定 |
| 範圍 | 開啟服務的方式、入口頁版面；取代 STATUS 的 O-2 |

## 決定

1. 新增開啟方式「分割畫面」並設為新 Vault 的預設：入口頁在左，服務分頁在右（`tabs.create({ splitWithTabId })`，Chrome 155+）。入口頁已在分割中就換掉右邊；API 不存在或失敗時退回新分頁並提示。
2. 入口頁寬度 ≤ 640px 時改為側欄版面（一行一個服務），≤ 220px 只留圖示；右邊正在開的服務加標示。
3. iframe 內嵌保留為實驗開關，不再擴充；O-2（每服務內嵌開關）取消。

## 理由

- iframe 內嵌被 YouTube（框架崩潰）、claude.ai（框架內不顯示側欄）擋下，且要移除服務的 CSP、放寬 SameSite。
- 2026-11-21 使用者實測分割畫面：Spotify、Claude（側欄正常）、YouTube 都能在右邊正常使用，再點別的服務會換掉右邊。
- 分割畫面兩邊都是頂層分頁，不需要移除任何安全標頭，DRM、DBSC 都不受影響。
- 調研：市面上「同頁多網站」的外掛都是 iframe 加移除標頭，有相同限制。

## 限制

- 只能在一般視窗分割；App 視窗（popup）和桌面捷徑開的入口頁會退回新分頁。
- 無法用 API 設定左右比例，靠使用者拖曳分隔線。
- 一次只能兩邊。

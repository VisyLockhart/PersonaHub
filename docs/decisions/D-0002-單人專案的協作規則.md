# D-0002 單人專案沿用工作流範本的部分規則

| | |
|---|---|
| 狀態 | 有效 |
| 日期 | 2026-11-20 |
| 決定者 | 使用者決定（「個人開發，導入適合的部分」、授權 Claude 直接 commit 並 push） |
| 範圍 | 協作流程 |

## 決定

1. 從 `claude-workflow-template` 沿用：`CLAUDE.md` 自動載入 STATUS / DECISIONS / CONVENTIONS、一檔一決策加索引與否決清單、STATUS 只記現況、驗證回報的階段用詞、LF 行尾。
2. 不沿用：多人認領與分工、PR 審查員、`ship` / `after-merge` skill、交接檔、待當面確認清單。
3. Claude 可以直接 commit 並 push 到 `main`，不必開 PR。

## 理由

單人開發不需要防止多人互相覆蓋，PR 流程和審查員只會增加成本；保留下來的部分是為了跨對話不重問、不重提已否決的方案。

## 否決的方案

| # | 方案 | 否決原因 | 重啟條件 |
|---|---|---|---|
| R-005 | 完整套用範本（PR、審查員、交接檔） | 單人專案用不到，徒增流程 | 有第二個協作者時 |
